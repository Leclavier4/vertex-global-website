# Vertex Global — Website

> Building Africa's next innovation layer.

Official website of **Vertex Global SARL**, an African Venture Studio based in Cotonou, Bénin.

## 🌍 Live

[vertexglobal.vercel.app](https://vertexglobal.vercel.app)

## 🛠 Tech Stack

- **React 18** — UI framework
- **Vite** — Build tool
- **Tailwind CSS** — Styling
- **Framer Motion** — Animations
- **React Scroll** — Smooth in-page navigation
- **Lucide React** — Icons

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
# → http://localhost:5173

# Production build
npm run build

# Preview production build
npm run preview

# Lint
npm run lint
```
